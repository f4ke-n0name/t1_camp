# t1_camp

В проекте применена архитектура с использованием зашифрованных JWT (JWE), где:

- Вся чувствительная информация внутри токена шифруется с помощью асимметричного RSA-шифрования.

- Токен можно расшифровать только с помощью приватного ключа, который хранится только на сервере (auth-service или web-gateway).

- Публичный ключ доступен другим сервисам, но он позволяет только зашифровать токен, а не расшифровать или изменить.

- Это защищает токен от прочтения третьими лицами (даже если токен перехвачен).

- Использование асимметричной криптографии исключает возможность подделки токена, потому что для генерации корректного токена нужен приватный ключ.

Таким образом, архитектура:

- Надёжно скрывает содержимое токена от посторонних,

- Исключает возможность подмены токена,

- Обеспечивает безопасность передачи данных по незащищенным каналам.


Для проверки работоспособности можно поднять postgres через compose.yml и запустить приложение
